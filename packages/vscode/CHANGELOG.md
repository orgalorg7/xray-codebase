# Changelog

## 0.2.0

- Go, Java, Kotlin, Rust, C#, PHP and Ruby, besides TypeScript, JavaScript and Python.
- Requests in one language link to the routes that serve them in another (`fetch` to a Go,
  Python or Java handler), so a backend change shows its frontend callers.
- The map's **Changes** view: how the architecture changed since a branch or commit.
- **Shared mutable state** in Insights and the sidebar: module-level variables some code changes
  and other code reads.

## 0.1.0

First release: the xray map in an editor tab, CodeLens with callers and blast radius, hovers,
Reveal in Map, Blast Radius, Find Where a Feature Lives, an Insights sidebar (import cycles,
hotspot files, possibly dead code) and a status bar item. TypeScript, JavaScript and Python.
